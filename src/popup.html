What's New
v0.25 New Pod image version badge
Each pod row in Deployment and DeploymentConfig pod lists now shows the image tag (e.g. 1.2.3) next to the Terminal / Logs / Events buttons. Immediately reveals mixed-version pods during rolling updates or failed rollouts. Hover the badge for the full image reference. Toggle per button type in Settings → Console features → Pod lists.
v0.25 Individual pod action button toggles
Terminal, Logs, and Events buttons can now be enabled or disabled independently in Settings → Console features → Pod lists. Previously they were controlled by a single switch.
v0.24 Cluster toolbar colour
Assign one of 8 distinct colours to each cluster's top navigation bar so browser tabs for different environments are immediately distinguishable at a glance. Pick a colour from the popup — it takes effect instantly and persists across sessions. Colours are stored per hostname independently of your credentials.
v0.23 Resource favourites & pinned section
Star any resource from its list or detail page to pin it at the top of that resource list. Favourites are stored per cluster and namespace, survive credential changes, and work across both namespaced and all-namespaces views. Toggle per cluster in Settings → Console features.
v0.22 Copy Login button in the console header
A "Copy Login" pill lives in the top navigation bar of every console page. One click opens a silent background tab, fetches your token through the OAuth flow, and writes oc login --token=… --server=… straight to your clipboard — no extra tab to close, no manual steps.
v0.21 Per-cluster credential overrides
Store a separate username and password for any cluster hostname — overrides the default credentials for just that cluster. Useful when different environments use different LDAP accounts or identity providers.
v0.21 Click title to copy resource name
Click any resource name in the page heading to instantly copy it to the clipboard — a brief green flash confirms the copy. Works on every resource detail page across all resource types.
v0.20 Pod list action shortcuts
Terminal, Logs, and Events buttons appear directly on every pod row in list pages. Skip the pod detail page entirely and jump straight to what you need.
v0.20 Route ↔ Deployment cross-links
Deployment pages show all their linked Routes — with clickable app URLs and copy buttons in the details panel. Route pages link back to the backing Deployment or DeploymentConfig.
v0.20 Force Delete button
Immediately removes pods stuck in Terminating using gracePeriodSeconds=0. Available on the pod detail page and on every row in pod lists.
v0.20 Pod owner link
Pod detail pages show a button linking directly to the parent Deployment, DeploymentConfig, StatefulSet, DaemonSet, or Job — resolved automatically from the pod's ownerReferences.
v0.1 Auto-copy oc login command
When the OAuth token pages open (via "Copy login command" in the user menu), the extension automatically clicks Display Token and copies the full oc login --token=… --server=… command to your clipboard.
v0.1 Auto-login
Automatically selects the LDAP identity provider, fills in your credentials, and submits the login form on any OpenShift cluster — zero per-cluster setup required.
